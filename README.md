## 🔄 Auto Update

</div>

<div align="center">

<img src="https://user-images.githubusercontent.com/74038190/238200426-29fd6286-4e7b-4d6c-818f-c4765d5e39a9.gif" width="500">

**GitHub Actions** প্রতিদিন **ভোর ৪টায় (BD Time)** স্ক্রিপ্ট চালায় এবং playlist আপডেট করে।

</div>

```yaml
name: Auto Update IPTV

on:
  schedule:
    - cron: "0 22 * * *"   # 10 PM UTC = 4 AM BD
  workflow_dispatch:

jobs:
  update:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"
      - run: pip install -r requirements.txt
      - run: python scripts/main.py
      - run: |
          git config user.name "Mahadi Hasan"
          git config user.email "mahadi@example.com"
          git add output/
          git commit -m "🔄 Auto update playlist" || exit 0
          git push
```
